PostgreSQL Data Types

- TEXT stores characters.
- JSONB parses and stores JSON structure.
- PostgreSQL arrays must be rectangular.
- node-postgres treats JS arrays as PostgreSQL arrays.
- JSON.stringify() makes the coordinate array JSON text for JSONB.
- PostGIS geometry stores spatial meaning.
- ST_GeomFromGeoJSON converts GeoJSON to geometry.
- ST_AsGeoJSON converts geometry for the frontend.
